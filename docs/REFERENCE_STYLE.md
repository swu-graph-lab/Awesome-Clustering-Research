# Reference-site design notes

The repository borrows the information architecture of the GDI Lab topics and publications pages:

1. stable topic abbreviations;
2. one normalized publication record containing year, authors, title, venue, paper, code, and class;
3. topic filters above the publication list;
4. reverse-chronological year groups;
5. a compact label on each publication card.

This repository adapts that structure in one important way: `class` becomes a `tags` array. Clustering papers frequently sit at the intersection of biology, hypergraphs, and LLMs, so a single mutually exclusive class would lose useful information.

The canonical source is `data/papers.json`. `README.md` and `docs/papers.json` are generated by `scripts/build_catalog.py`; the static page reads the generated JSON at runtime.
