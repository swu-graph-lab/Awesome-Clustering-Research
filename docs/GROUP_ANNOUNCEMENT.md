# 群公告（可直接转发）

本群用于共同建设组内的 GitHub 聚类研究知识库，方便组内同学系统学习、查找论文和复现实验。

知识库目前围绕三条相互交叉的主线整理：

- `BIO`：生物与医学聚类；
- `HG`：超图聚类；
- `LLM`：LLM 增强聚类。

论文统一按年份倒序排列，并在每篇论文后标注方向标签。一篇论文可以同时属于多个方向，例如，用超图方法做生物数据聚类标为 `[BIO+HG]`，用 LLM 做超图聚类标为 `[HG+LLM]`。同一篇论文只收录一次，通过组合标签体现交叉关系。

欢迎大家补充高质量论文、官方代码和必要的简短说明。新增内容请尽量核对论文标题、作者、年份、会议或期刊、论文链接、官方代码链接及标签，避免只复制二手列表。
